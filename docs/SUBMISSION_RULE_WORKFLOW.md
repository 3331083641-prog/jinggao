# 联合提交规范检查

规则库的「导入规则」可一次选择 1–10 份 PDF / DOC / DOCX / TXT / MD，合并进入同一确认抽屉。每个检查项保留来源文件、SHA256 和条款原文；保存后仍需在新建检测中选择该规则集。DOC 使用本机 Word 只读转换，宏与链接更新关闭；临时文件在成功和失败路径清理。缺少 Word 时需另存为 DOCX。

中文提交条款的结构匹配用于提出检查草案，不能替代人工确认。未识别的要求保留为人工复核。模板登记页与匿名规范同时存在时，登记封面身份线索标 REVIEW。未断言登记封面必然违规，也不以模板证明其必然允许。

选中导入或自定义规则后，可在右侧详情点击「删除规则」，确认后从规则库和新建检测选项移除。内置基础规则保留。删除采用本机归档，历史检测与报告保留原快照，历史任务仍可使用该快照复检；新任务不能再选择已删除规则。

新建检测中的「自定义规则」支持勾选多份已导入规则，最多 10 份、合计 100 项。所选规则在一个 Run 中联合执行，分别保留来源文件、原文和规则版本；同名检查项使用独立 ID。模板与匿名要求跨文件组合时仍保留适用范围待确认。联合快照仅归属于检测记录，不额外生成规则库条目；复检沿用原联合快照，之后删除来源规则不影响已有记录。导入规则本身也可一次选择多个文件。

PDF 检查读取真实页码、坐标、中文字体和字号。摘要篇幅按摘要至关键词所在页计算，不能将「摘要一般不超过两页」变成全文两页上限。标题识别排除正文数量和代码行号；字体异常按字体类型显示代表位置，完整文本表层仍保留。PDF 无法还原原始 Office 单倍行距语义，故行距仍需人工确认。编号引用对应和顺序检查不证明文献真实、模型来源可靠。

AI 规则保留条件适用性：没有声明不代表没有使用；发现 AI 辅助代码标记时检查附近注释的四类工具字段。全局声明或外部支撑材料引用不被当作所有程序、分析结果已完成注释的证明。尚未提供的支撑材料和独立思考等事项留 REVIEW。

历史任务可删除单条或清理 PDF 任务。删除会同时移除关联 Run、报告及应用内上传副本；只允许访问应用 uploads/reports 目录。删除前备份至本机数据目录 `trash/<archive_id>/manifest.json` 和对应文件。运行中任务不能删除，原始用户文件不动。复检生成独立 Run，人工判断不覆盖原始证据和自动统计。

报告中心可从行内「··· → 删除报告」或详情底部删除单份报告。删除标记独立存于 SQLite，不改动检测 Run、证据或人工判断；应用内导出 PDF 备份后移除。刷新、重启不会恢复已删除条目；从工作台主动重新导出可恢复这份报告。删除一个 Run 的报告不影响同任务的其他 Run。删除整个历史任务时一并清理报告删除标记。

证据页支持保存待确认说明，以及确认、排除和已修复记录。待确认说明随报告导出，原始证据和自动统计保留，避免将缺少材料或官方解释的事项提前判为通过。

验证：`pytest` 包含条件范围、摘要限制、模板匿名冲突、编号标题误报、未知字体、旧 DOC 文件头、批量导入来源及删除备份测试；Playwright 包含联合导入 → 确认 → 上传 → 检测 → 待确认记录 → 导出 → 删除全过程。真实材料仅用于本机验收，不作为仓库测试数据。
