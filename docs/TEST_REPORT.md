## 规则边界

API 真实导入“正文不得出现学校名称”或“禁止出现项目编号”，随后上传同时含学校、电话、邮箱、导师、项目编号的合成材料。每个任务只执行确认的单条规则，只返回对应目标证据。切回内置匿名评审时，其 8 项规则与联系方式检查恢复。AI 显式标识、Logo 和文字质量均受启用 Rule 控制。

规则全文与 source_documents 保留；不把标题、日期、引言转成检查要求。未知要求保留人工判断，不借用默认规则补全。没有匹配证据的启发式识别不产生虚假 PASS，覆盖限制单列系统诊断。

## 连续阅读

合成 89 页 PDF 包含可验证的 95 条禁止词证据。三个尺寸均可连续滚到末页、直接点任意缩略图、同步当前页；高质量 Canvas 少于 9 个。右栏可滚到第 95 条；滚轮不带动网页正文。点击末尾证据定位第 89 页后，中央仍可继续自由滚动。其他测试覆盖 Tab 不重建 Viewer、Run 切换和预览快速开关。

## OCR 回归

fixtures/ocr 包含正常小字体、图表、中英文、乱码、缺字框、替换字符、AI 标识与模糊图片。四种正常图片实际经过 RapidOCR，未产生文字质量风险。分析器测试置信度 0、0.3、0.65、0.99 均不能单独触发 REVIEW；明确损坏字符即使高置信度也被识别。无文字照片不因空 OCR 结果报告风险。损坏 PDF、取消检测和启动恢复均单列系统诊断，不虚构合规 REVIEW 数量。

AI 标识检测仅在对应规则启用时执行；Logo 未被规则禁止时不产生该合规 Finding。乱码和缺字框由明确字符证据验证；图片 fixture 不能证明 OCR 会保留所有视觉损坏，严重模糊和非语义乱码仍是已知限制。
