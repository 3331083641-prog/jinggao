# 检测覆盖与复检证据

覆盖矩阵在工作台/证据页默认折叠，不新增导航。每条快照规则执行后记录 rule_id、实际检测器、scope、executed、状态、覆盖说明和规则来源。历史没有矩阵的 Run 不倒推为已验证。

| 状态 | 实际含义 |
|---|---|
| VERIFIED | 确定性检测器已检查当前实现范围；不是合规结论 |
| PARTIAL | 范围关闭、解析/OCR 缺口、启发式实体、图形候选或原图质量未穷尽 |
| MANUAL | 条件、例外、创新/真实性等无可靠自动证明路径 |
| UNAVAILABLE | 未执行或没有可验证表层 |

学校名称识别只覆盖有限词法、别名、OCR和语境，因此保留 PARTIAL。Metadata Detector 的 VERIFIED 只承诺实现支持的 PDF/OOXML 属性，不承诺整个文档不存在身份。Visual Provider 仅在生效视觉规则且图片范围开启时调用：OCR 身份文字、紧凑徽章几何候选、可选本地视觉描述；图形只 REVIEW，不直接 FAIL。未配置模型仍可工作，不把普通图片当风险。视觉首版最多32个图像区域，剩余单列诊断。

Run Diff 按规则 ID、source_type、页码、归一化证据配对；保留旧、新 Finding 链接和原始 Evidence。快照 SHA、范围、完成状态一致才可比较整改效果。没有再命中只称“已消失”；新覆盖 VERIFIED 且实际存在该规则 PASS 才显示 FAIL/REVIEW → PASS。不同快照只并列展示，不能据数字宣称改善。

证据文本变化可能按“旧项消失 + 新项新增”展示，而非假装建立语义同一性。新增风险和 REVIEW→FAIL 明确展示。比较不是证明材料风险已全部消失。
