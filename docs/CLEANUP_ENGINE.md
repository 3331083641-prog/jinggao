# 安全整改副本

工作台既有整改 Tab：选择安全操作 → preview → 列出结构变化 → 用户点击生成 → 新文件 → 校验完整性 → 使用原 Run 的规则快照和范围自动创建 Run N+1 → Diff。原文件永不覆盖，预览记录 SHA 和一次性 token；原稿变化、无变化、重复 token、运行中任务均拒绝。

| 格式 | 支持 | 保留 / 不支持 |
|---|---|---|
| PDF | 清空 /Info 与 XMP 元数据，副本页数、提取文字和页内容流逐页比较 | 不重排正文、不删 PDF 批注；拒绝加密、表单或签名 PDF |
| DOCX | 清除作者/最后修改人/公司等身份属性、自定义属性、批注及引用、直接 vanish/webHidden 文字、危险链接目标、修订作者日期 | 修订内容和结构保留；不自动接受/拒绝修订；样式继承隐藏需人工 |
| PPTX | 身份/自定义属性、批注部件及引用、危险链接目标 | 不自动删除隐藏图形、隐藏幻灯片或任何正文内容 |
| TXT / MD | 无结构清理 | 人工整改并上传复检 |

Office 按 ZIP/XML 精确修改已选结构，禁止 DTD、签名、宏、重复部件与超限包；危险外部链接改成 `about:blank`，保留关系 ID 和显示文本。重写后 testzip、所有 XML 重新解析并由 python-docx/python-pptx 重新打开。单部件 30 MiB、解包总计 300 MiB 上限。失败时只删除刚生成的副本，原稿不动。

可选清除隐藏文字具有明确副本预览与用户选择，不作用于可见正文。学校/人名/导师/基金/项目、公式、引用和图片从不直接自动删除。已签名材料可能因任何改写失效，因此直接拒绝。结果中保存原 SHA、所选操作、实际变化和父 Run，报告同步披露。

API：GET `/api/runs/{id}/cleanup-options`，POST `cleanup-preview`，POST `cleanup-copy`；GET `diff`。使用已有任务锁及异步任务池，阅读器不等待 AI/复检执行。
