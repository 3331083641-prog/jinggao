# 比赛对应

申报方向：开源赋能的 AI 应用创新。

官方来源：https://www.aicomp.cn/tracks/tracks-5/4924.html，核对日期 2026-10-02。已阅读官方附件 1《竞赛规则及作品提交要求》和附件 2《技术报告参考大纲》。

| 要求 | 对应实现与证据 |
|---|---|
| 真实问题 | 提交前匿名泄露与文档隐藏信息检查 |
| AI + 开源实质融合 | RapidOCR 本地神经网络识别图片文字；scikit-learn 局部证据语境辅助；规则由明确条款映射并待确认 |
| 完整可运行流程 | 上传→规则→解析→证据→人工确认→整改复检→报告 |
| 原创与实质改进 | 统一 Surface、规则驱动 Pipeline、独立系统诊断、保留多次 Run |
| 开源披露 | 清单、依赖锁定、许可证盘点与发布审计 |
| 可验证性 | 单元/API/Playwright 测试、合成测试材料、benchmark 可复现脚本 |

当前不宣称论文级算法优势；小型合成集指标不外推为真实世界性能。Logo 视觉理解尚待实现。

附件评分结构：问题与场景价值 15 分；创新性与方案设计 20 分；AI 与开源融合 20 分；实现完成度与可验证效果 25 分；开放成果与复用价值 15 分；材料规范与表达 5 分。不能以漂亮 UI 代替功能与证据。

赛事匿名要求包含参赛学校名称、学校 Logo 与指导教师信息。净稿可导入这些真实条款，保留规则原文，再映射到单位 / 人物 / 图片人工复核检测器；并非内置规则冒称官方完整要求。

材料安排：技术报告 PDF 正文建议 15 页以内且不超过 10MB；视频 MP4 3–5 分钟，不超过 300MB；披露开源资源、开发 AI 工具与团队实际审核贡献。正式比赛材料尚未制作或提交。
