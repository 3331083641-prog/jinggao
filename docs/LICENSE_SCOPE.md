# 许可范围与发布边界

2026-10-06。当前状态：**自主源码 MIT 候选，团队权利确认尚未完成；根 LICENSE 暂不建立。**

MIT 的候选范围是团队自主编写的前后端源码、脚本、原创合成测试与项目文档，前提是团队持有相应权利且全部共同权利人同意。Codex 辅助产出并不等于已经取得团队版权证明。本文件是范围说明，不是现阶段的授权书。

| 分类 | 仓库处理 | 许可边界 |
|---|---|---|
| A 自主源码 | 保留源码及修改记录 | 待团队确认后可独立采用 MIT |
| B Python / npm 依赖 | 锁文件与安装说明，不发布依赖目录 | 各自上游许可，项目 MIT 不覆盖 |
| C OCR / ONNX 权重 | 不提交、不打包、不重新分发 | 用户通过上游依赖取得；遵循模型及发行包许可 |
| D 本地 LLM / VLM | 只提供 loopback 接口和实验记录 | 模型权重及运行器遵循各自许可 |
| E UI 参考图 | 不提交参考原图 | 不主张参考资料版权 |
| F 测试素材 | 原创合成数据；真实用户材料排除 | 合成标签待团队审核，不声称已独立人工标注 |
| G 字体 | 使用已安装字体或 CID 引用，不提交字体文件 | 系统字体及 PDF.js 字体保留上游边界 |
| H React / Three.js / FastAPI 等 | 安装版本与 notices 保留 | 上游版权和许可不因本项目改变 |
| I 二进制动态库 | 不发布 DLL / 完整环境 | GEOS、FFmpeg、PDFium、GCC runtime 等单独审计 |
| J 用户自行安装模型与文件 | 不纳入 Git | 用户文件、外部模型均不适用项目候选 MIT |

现有 third_party_notices、精确版本盘点和 [许可审计](OPEN_SOURCE_LICENSE_AUDIT.md) 保留。对源码单独授权并不要求把依赖或权重改成 MIT；OCR 历史权重来源链属于将来重新分发模型/二进制包的审核事项，不是自主源码版权证明。

未来制作离线安装包时，需重新核对实际随包的权重、第三方库、字体、NOTICE、源码获取和动态链接义务。当前仓库不附带任何本地模型，也不自动下载大型模型。

剩余人工确认仅针对自主成果：团队是否拥有源码、程序化资产、原创测试和文档的相应权利；所有共同权利人是否同意 MIT；是否存在未披露的第三方复制内容。未获确认前保持 BLOCKER，不创建正式 v0.1.0 Release。
