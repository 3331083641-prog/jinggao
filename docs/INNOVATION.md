# 自主实现与创新

1. Rule-aware：统一规则 Schema，将提交规范草案映射到可执行 detector，导入规则保留原文依据并需要确认。
2. Document Surface：正文与元数据、Office 隐藏内容、批注修订、链接、图像共用可定位证据结构。
3. Evidence-first：每个结果包含规则、检测器、真实证据、位置、原因、整改建议。
4. Unknown != Clean：解析缺口和不可确认的视觉、语义检查进入 REVIEW。
5. 复检保留旧 Run，显示 FAIL/REVIEW/PASS 差异；判断记录不删除原始检测证据。
6. Local-first：本地存储、解析、OCR、规则分类，不调用公网 AI。

## 比赛终版增量

- 有边界的语义规则编译：模型只解释精确原文，授权校验阻断新增目标/扩大范围/删除例外，未配置模型仍可运行。创新在可审查规则授权与证据链，不声称通用理解算法突破。
- 安全副本闭环：可预览的结构修改、原稿 SHA 不变、格式重开校验、同快照独立复检、旧新 Evidence 对比；不自动删改科研正文。
- Coverage 与结论分离：每项实际执行后记 VERIFIED/PARTIAL/MANUAL/UNAVAILABLE，诊断不混入违规；OCR 没识别损坏字形不冒充原图 PASS。
- 规则门控视觉：OCR 身份文字与纯图形候选分层，徽章候选不直接 FAIL，未配置视觉模型有明确降级。实体识别以 regex/alias/context/adapter/decision 分层，而非一个高召回正则冒充确定事实。
- 可复现开放证据：保留 v1，增设句子/真实格式文档 v2，候选与确定结论指标分开，记录真实误报漏报；CI重复关键闭环。
