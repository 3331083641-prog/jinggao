## 已形成的产品闭环

真实规则 → 上传材料 → 文档表层解析 → 规则检测 → 证据 → 原文定位 → 人工判断 → 上传整改稿 → 保留多次 Run 的复检对比 → 中文 PDF 报告。

| 范围 | 当前实现 |
|---|---|
| 基础工程 | React / TypeScript / Vite，FastAPI，SQLite WAL；依赖锁定；生产材料与测试 DB 隔离 |
| UI | 六项导航；首页、新建、扫描、三栏工作台、证据链、规则库、历史 Drawer、报告中心；自研 SVG Hero 与 reduced-motion |
| 规则 | 三套明确标注为自研建议的基础规则；规则文件语义草案；原文依据、用户确认、自定义精确禁用词 |
| 文档 | PDF、DOCX 为优先能力；PPTX OOXML 检查、TXT/MD 支持；统一 Surface |
| 多层检测 | 中文身份候选、作者属性、页眉页脚、批注、修订、隐藏文字、超链接、图片 OCR、嵌入对象存在性 |
| AI | RapidOCR 本地神经网络；自建中文语料的规则分类与局部证据语境分类；未使用外部通用模型 API |
| 可信状态 | PASS / REVIEW / FAIL；未完成状态 UNKNOWN；缺失覆盖不判 CLEAN；模型提示不自动升级 PASS |
| 定位 | PDF 真实页码/bbox；裁切旋转坐标未经确认时不绘制；DOCX 原文或真实 XML 部件证据，无伪页码 |
| 复检 | 独立 Run、规则快照、原文件保留、数量对比；人工记录不改写原始结论 |
| 报告 | 从真实 Run 生成中文 PDF，包含规则、位置、证据、原因、建议、人工记录及 AI 辅助提示 |
| 比赛资料 | 架构、评分对应、创新、开源清单、许可审计、AI 使用、测试、3–5 分钟演示脚本 |

界面中没有登录、设置、账户、通知、付费、多租户或商业统计。任务、规则和结果来自 SQLite 与实际检测；参考图的论文、学校、日期和数字未硬编码进产品。

## 明确待完善

1. **视觉模型**：Logo 目前提供图片证据和人工复核，Qwen3-VL 尚未集成。
2. **识别覆盖**：机构简称、英文单位、无标签姓名、固定电话等存在漏检；完整论文上下文判别仍需更大语料和真实匿名材料评测。
3. **文档深层结构**：PDF 隐藏图层、附件内部；Office 样式继承隐藏、离页图形等未完整覆盖，明确 REVIEW。
4. **格式规范**：当前支持可读性和导入的页数上限；不宣称已覆盖所有投稿排版规则。
5. **规则导入**：小型语义分类器为辅助草案；复杂复合条款须人工编辑确认，扫描式规则文件尚未接入 OCR 草案生成。
6. **视觉验收**：已修正并留存对照，暖白、墨蓝、金色和页面结构按参考复刻；SVG 纸张质感、部分密度/留白仍与参考有差异，不宣称像素完全一致。
7. **发布准备**：历史 OCR 权重精确来源链与二进制再分发审计尚未闭合；遵照要求暂未建立根 LICENSE。自主源码候选 MIT。无公开仓库上传或正式比赛材料提交。
